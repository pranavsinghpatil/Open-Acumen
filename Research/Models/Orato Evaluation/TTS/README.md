# Orato TTS Hindi Demo

This folder contains a Hugging Face Space demo for Hindi text-to-speech.

## What it does

- Accepts Hindi text
- Generates spoken audio in the browser
- Runs on Hugging Face Spaces with Gradio

## Files

- `app.py` - Gradio Space entrypoint
- `requirements.txt` - Python dependencies

## Model

- `facebook/mms-tts-hin`
